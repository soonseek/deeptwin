# DeepTwin 수정 관제 UI 시제품

비개발자가 멀티에이전트 환경의 구조와 조작을 검토하는 로컬 시제품입니다. 설계·실행·개선은 같은 환경의 작업 영역이고, 작업공간·대화·그래프는 같은 대상을 다루는 보기입니다. 그래프, 수행·시도, 입력·출력·전달, 자기 버전과 고정 사례의 반복 비교를 연결합니다.

자동 코드 검사 57개와 브라우저 검사 22개가 통과했고 실제 캡처를 수집했습니다. 검사 범위, 화면 관찰과 남은 확인 사항은 [화면 검토 기록](../docs/ui/control-workspace-review.md)에 구분합니다. 자동 검사 통과는 전체 시각 검토나 사용자 화면 수용을 뜻하지 않습니다.

## 담당 에이전트의 실행 방법

작업 폴더에서 `node control-prototype/server.mjs`를 실행합니다. 기본 주소는 `http://127.0.0.1:4183`이며, 사용자는 에이전트가 열어 둔 화면을 검토합니다. `PORT`를 지정하면 다른 포트를 사용할 수 있습니다. 충돌한 기존 프로세스를 종료하지 않습니다. 서버는 직접 실행할 때 127.0.0.1에만 연결하고, 가져오기만 해서는 서버를 시작하지 않습니다.

합성 원본과 미리보기는 `control-prototype/assets/`에 있습니다. 다시 생성할 필요가 있을 때만 프로젝트의 PDF 스킬 절차를 먼저 따르고 `node control-prototype/build-assets.mjs`를 실행합니다. 패키지 설치나 외부 계정 연결은 필요하지 않습니다.

현재 환경의 Node 경로:

```text
/Users/soonseekyang/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node
```

## UI에서 검증하는 기능과 미연결 기능

검증하는 조작은 그래프·시도·파일·비교 초점·회차 탐색, 원 파일 접근, 형식별 표시, 전체·부분 초안, 대화 메모, 메모리 파일 첨부, 기록 선택과 출처 표지 가림, 세 보기 왕복과 탭 보관입니다. 정확한 원본·입력·시도·범위가 작성 내용을 구별하며, 파일 첨부도 같은 범위에 연결합니다.

자료 자동 해석, 자연어 설계 생성·병합, 실제 에이전트·도구 수행, 구독 인증·API 과금, 탐구·크리틱 추론, 재실험·평가·승인·운영 반영, 로그 묶음 추출·제작자 전송은 연결하지 않았습니다. 설계 병합과 개선 사례는 사전 작성된 예시이고, 버튼을 눌러 실제 작업이 성공한 것으로 표시하지 않습니다.

고정 합성 사례는 현재 입력과 별개입니다. 새 초안에 사전 가설·점수·변경 후보가 붙지 않습니다. PDF 원본과 SVG 파생 미리보기를 구별합니다. CSV는 통제된 합성 자료의 표 표시이며 임의 CSV 가져오기 기능이 아닙니다. 부분 선택은 문서의 실제 문자 범위 또는 형식별로 선언된 영역이고, 범용 PDF·이미지 편집 기능은 아닙니다. 일반 화면은 업무 언어를 쓰고 내부 탐구 경로는 감사에서 확인합니다.

## 보관과 파일 경계

문자 초안과 메모는 `deeptwin:control-ui:v1` 하나의 sessionStorage 키를 사용합니다. 각 필드는 20,000자, 직렬화된 상태는 2,000,000자 이하로 제한합니다. 영구 보관이나 비밀 저장을 보장하지 않습니다. 이전 시제품 키는 읽거나 변경하지 않습니다. 손상되거나 읽지 못한 보관본은 자동으로 덮어쓰지 않고, 쓰기·초기화 실패 시 현재 메모리 내용을 유지합니다. 초기화는 확인 후 이 시제품의 키만 지웁니다.

첨부 파일은 최대 5 MiB이며 탭 메모리에만 있습니다. 새로고침 후 파일 바이트를 복원하지 않습니다. 사용자가 첨부한 SVG·PDF를 실행하거나 문서에 삽입하지 않고, 래스터 이미지 외에는 메타데이터와 원 파일 접근만 제공합니다. 허용하지 않은 형식이나 크기의 교체 요청은 기존 첨부를 보존합니다. 시험에는 중립적인 합성 자료를 사용합니다.

서버는 지정된 UI 모듈과 검증된 합성 파일 경로만 제공합니다. 소스 서버·테스트·빌더·저장소 문서·`.git`은 공개하지 않습니다. 페이지의 외부 연결, 폼 전송, 삽입 객체·프레임은 제한하며 실제 모델이나 외부 도구 요청은 발생하지 않아야 합니다.

## 검사 명령과 해석

순수 코드·파일 검사:

```sh
node --test control-prototype/tests/fixtures.test.mjs control-prototype/tests/state.test.mjs control-prototype/tests/primitives.test.mjs control-prototype/tests/workspace.test.mjs control-prototype/tests/server.test.mjs
```

브라우저 검사에는 이미 설치된 Chrome과 번들 Playwright를 사용합니다. `CONTROL_PLAYWRIGHT_MODULE`을 지정하지 않으면 명시적으로 실패하며 검사를 건너뛰지 않습니다.

```sh
CONTROL_PLAYWRIGHT_MODULE=/Users/soonseekyang/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright/index.mjs node --test control-prototype/tests/browser.test.mjs control-prototype/tests/browser-review.test.mjs
```

브라우저 회귀 검사는 독립된 브라우저 컨텍스트에 합성 자료만 입력합니다. 실제 원본 다운로드, 네 비교 회차의 8개 수행·60개 시도·100개 수신 연결, 부분 초안, 첨부 수명과 저장 실패를 검사합니다. 화면 행렬은 3개 작업 영역 × 3개 보기 × 3개 폭(1440/1024/390) × 2개 테마입니다. 본문 넘침·이미지·브라우저 오류·외부 요청과 지정된 텍스트의 명암 대비를 검사합니다. 캡처는 `control-prototype/review-output/`에 생성하며 실제 시각 확인 전에는 화면 품질 합격으로 기록하지 않습니다.

자동 입력과 DOM Range 검사는 물리 키보드의 한국어 IME 조합, 전체 접근성, 사용자 제품 정체성 수용을 인증하지 않습니다. 실제 두 구독 지원·도구 수행·학습·전이·회귀 효과는 별도 검증 대상입니다.
