# 첫 사용 제품 셸 — T023 디자인·구현 검토 기록

상태: 2026-09-08 디자인 기준을 브라우저 개발 슬라이스에 적용하고 독립 UX 재감사를
통과했다. 사용자가 승인한 첫 사용 방향과 이후 직접 정정을 코드 배치 기준으로 압축한
것이며, T025/T090의 배포 자격증명·제공자 실행 통합이나 최종 시각 승인을 뜻하지 않는다.

## 제품 경계

여기서 제품 셸은 네이티브 창이나 설치 런처가 아니라, 자체 호스팅 인스턴스가 제공하는
공식 DeepTwin 브라우저 UI를 뜻한다. Docker/Compose/Portainer는 이 화면 밖의 배포·운영 수단이다.
Claude는 API 연결만 제공하고, Codex 구독은 인스턴스가 소유한 관리형 어댑터·실행기로 연결한다.
사용자는 제공자 앱이나 CLI로 이동하지 않고 이 브라우저 UI에서 제공자·모델·에이전트·권한을
관리한다. 에이전트의 브라우저 및 외부 도구 사용과 텍스트에 한정되지 않은 원형 산출물 생성도
인스턴스가 실행하며, 이 화면은 그 상태·계보·실제 파일을 관제하고 검토하는 표면이다.

## 한 화면의 한 가지 일

- **대상:** 업무 설명과 자료로 자기 업무용 멀티에이전트 관제 환경을 만들려는 비개발자.
- **첫 화면의 일:** “이 일을 맡기기”에 필요한 원문을 잃지 않고 입력한 뒤, 시스템이 이해한
  내용을 확인하는 것.
- **정체성:** 일반 채팅 앱이나 모델 설정기가 아니라, 입력하던 브라우저 작업면이 실제
  에이전트 전달 그래프로 자라나고 그 그래프가 그대로 실행 관제가 되는 자체 호스팅
  DeepTwin 웹 환경이다.

모델, 과금 방식, 실행 한도와 음성은 이 일을 가능하게 하는 제어다. 첫 화면의 주제가 되지
않는다. 철학 렌즈, 크리틱 독립성, 계보와 평가 내부 명칭도 첫 이용의 선행 학습 항목으로
노출하지 않는다.

## 토큰과 글자

기존에 사용자가 채택한 제품 언어를 유지한다. 새 유행 팔레트나 랜딩 페이지 분위기를 만들지
않는다.

| 역할 | 밝은 화면 | 어두운 화면 | 용도 |
|---|---|---|---|
| `canvas` | `#F4F7F7` | `#10191E` | 한 업무가 이어지는 바탕 |
| `surface` | `#FFFFFF` | `#18262D` | 입력·산출물·상세 면 |
| `ink` | `#1B3037` | `#E5EFF0` | 본문과 주요 판단 |
| `muted` | `#53676E` | `#ACC0C6` | 출처·상태·보조 설명 |
| `line` | `#CFDDDF` | `#3C535D` | 실제 전달·관계·구획 |
| `signal` | `#087F83` | `#62D2CE` | 현재 초점과 실행 흐름 |

한국어 제목·본문은 라이선스가 확인된 OS `system-ui`를 사용하고, 모델 ID·파일 형식·실행 ID만
`ui-monospace`를 쓴다. 제목은 과장된 랜딩 페이지 크기가 아니라 현재 업무의 이름과 상태를
읽히게 한다. 외부 웹폰트나 런타임 다운로드를 추가하지 않는다.

## 고유한 상호작용

기억될 한 요소는 **같은 업무 면의 형태 전환**이다. 입력 카드가 사라져 별도 대시보드로
이동하는 대신, 원문·자료를 왼쪽의 지속 가능한 입력 근거로 남기고 오른쪽/아래에 업무 이해가
붙는다. 이해가 확인되면 그 영역이 구조가 다른 실제 후보 그래프로 확장되고, 승인한 그래프가
실행 상태와 산출물 전달을 표시한다. 장식 애니메이션 대신 이 한 번의 공간 변화만 짧고
`prefers-reduced-motion`을 존중해 사용한다.

이는 다음 세 상태를 설명하기 위한 도식이지 화면 상단에 `1/2/3` 단계 표시를 만들라는 뜻이
아니다.

```text
빈 업무
┌────────────────────────────────────────────────────────────┐
│ 어떤 일을 맡기고 싶으세요?                                 │
│ [설명 · 실시간 음성]                       [자료 추가]      │
│                                                            │
│  Codex 구독 · 현재 모델 ▾       실행 한도 ▾   [이해하기]   │
└────────────────────────────────────────────────────────────┘

이해 확인
┌──────────────────────────────┬─────────────────────────────┐
│ 원 설명 · 자료 · 읽기 상태   │ 이 업무를 이렇게 이해했어요 │
│ 수정 가능한 같은 입력 면     │ 결과/제약/빈칸 · 근거 펼치기 │
│                               │ [말로 바로잡기] [구성 보기] │
└──────────────────────────────┴─────────────────────────────┘

환경 제안과 실행
┌──────────────────────┬─────────────────────────────────────┐
│ 업무 근거/대화/산출물 │  실제 역할·전달·통제 그래프         │
│ 필요한 만큼 접기      │  [노드: 역할 · 모델 · 산출물 형식]  │
│                       │  후보 차이 → 승인 → 동일 그래프 실행 │
└──────────────────────┴─────────────────────────────────────┘
```

## 모델·한도·음성의 위치

- 연결 제공자와 현재 업무 기본 모델은 입력 행동 바로 위의 한 줄 요약으로 보인다. 펼치면 실제
  카탈로그에서 확인한 모델/지원 기능/인증·과금 방식을 고르며, 연결되지 않은 제공자를 강제하지
  않는다.
- `Codex 구독`, `Codex API`, `Claude API`는 서로 다른 결제·인증 경로다. 자동 대체하거나 같은
  연결처럼 표시하지 않는다. Claude 구독 선택은 만들지 않는다.
- 환경 후보가 나온 뒤 각 그래프 노드는 실제 기본값의 출처와 선택 모델을 보인다. 노드에서
  개별 변경하거나 여러 노드에 일괄 적용할 수 있지만, 이를 첫 입력 필수 설문으로 만들지 않는다.
- 마이크는 설명 입력 안의 명시 버튼이다. 녹음 중, 잠정 전사, 확정 전사를 구별하고 사용자의
  키보드 입력/한글 조합을 덮어쓰지 않는다. 음성 실패가 텍스트·파일 저장이나 다음 재시도를
  막지 않는다.
- 실행 한도는 “이번 요청에서 무엇까지 허용되는지”를 요약하고 필요할 때만 펼친다. API 비용과
  구독 한도를 같은 금액으로 위장하지 않는다.

## 실패와 복귀

- 제공자 연결, 카탈로그, STT, 파일 읽기, 저장, 업무 이해 중 하나가 실패해도 원 설명과 이미
  추가한 자료는 남는다.
- 오류는 내부 모듈 이름 대신 지금 유지된 것과 다음 행동을 말한다. 예: “모델 목록을 확인하지
  못했습니다. 입력은 저장됐습니다. 연결을 다시 확인하세요.”
- 새로고침·재시작은 저장된 업무를 다시 열며, 진행 중이던 외부 요청을 묵시적으로 재전송하지
  않는다.

## 구현 전 자기 비평

- **일반 챗봇 위험:** 큰 대화 말풍선과 단일 전송 버튼만 남으면 그래프 기반 환경이라는 정체성이
  사라진다. 그래서 이해 이후 같은 면에 실제 역할·전달 구조가 등장해야 한다.
- **관리자 콘솔 위험:** 제공자, 모델, 예산, 권한 카드를 처음부터 나열하면 사용자가 일을 맡기기
  전에 시스템 운영자가 되어야 한다. 기본값 요약 한 줄과 상황별 펼침으로 제한한다.
- **고정 단계 위험:** 위 상태를 진행 막대와 완료 버튼으로 번역하지 않는다. 사용자는 일부만
  확인한 뒤 자연어로 돌아가 수정할 수 있고, 제품은 실제 상태로 다음 가능한 행동을 제시한다.
- **장식 그래프 위험:** 후보는 이름이 다른 카드 세 개가 아니라 에이전트·산출물·전달·통제 관계가
  다른 실제 그래프여야 한다. 유효 후보가 부족하면 빈 수를 채우지 않는다.

## T023 확인 기준

1. 360px·1024px·wide와 밝은/어두운 화면에서 첫 행동이 업무 설명임을 알 수 있다.
2. 키보드만으로 입력, 자료, 음성, 모델 요약, 이해 요청과 오류 복귀를 사용할 수 있다.
3. 모델/한도 상세를 한 번도 펼치지 않아도 안전한 기본 경로가 이해되며, 펼치면 실제 연결 경로와
   기능만 보인다.
4. 저장 실패·카탈로그 실패·세션 만료·이해 취소 뒤에도 원 입력과 자료가 보존된다.
5. 이후 T037/T048이 같은 영역을 후보 그래프와 실행 관제로 확장할 수 있고, 별도 관리 앱을
   다시 만들 필요가 없다.

스크린샷은 위 기준의 렌더링 증거일 뿐 실제 사용자 이해도나 그래프/DeepTwin 효과의 증거로
승격하지 않는다.

## 구현 뒤 독립 검토

- 일반 행동은 제공자 이름이 아닌 `업무 이해하기`로 고정했다. 현재 실제 연결된 Codex 구독
  실행 경로만 활성화하며, Claude API와 Codex API는 선택·저장할 수 있어도 실행기 미연결을
  숨기지 않고 입력을 보내지 않는다.
- 원 입력에 합류하지 않는 대화는 기본 접힌 `업무 메모`로 구별했고, 현재 이해 요청에는
  포함되지 않음을 표시한다. 최초 이해 결과가 나타날 때 모델·한도·전송 상세만 접고,
  사용자가 이후 다시 펼친 상태는 보존한다.
- 입력 포커스, 연결 패널 초점 이동, 브라우저 마이크와 인스턴스 전사의 책임 경계, 390px
  적층을 실제 브라우저에서 검사했다.
- 루트 재검증은 T023 브라우저 8/8 및 관련 첫 사용·이해·음성 묶음 50/50 통과였고, 별도
  비평 에이전트의 최종 판정도 PASS였다. 이는 그래프 생성·실행·DeepTwin 효과나 전체 T023
  제공자 gateway 완료 증거가 아니다.
