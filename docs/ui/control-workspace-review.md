# 수정 관제 작업대 화면 검토

대상: `control-prototype/`. 기존 실패 시제품 `prototype/`와 별도입니다.

근거: [UI 명세 §10–11](../superpowers/specs/2026-09-06-deeptwin-ui-structure-design.md#10-환경-맥락-유지형-작업대--채택된-연결-구조), [구현 계획 Task 7](../superpowers/plans/2026-09-06-deeptwin-control-workspace.md#task-7-failure-path-verification-and-actual-screen-review).

## 재현 방법과 결과 기록

검사 파일: `control-prototype/tests/browser-review.test.mjs`. 실행 명령:

```sh
CONTROL_PLAYWRIGHT_MODULE=<node-runtime>/dependencies/node/node_modules/playwright/index.mjs node --test control-prototype/tests/browser-review.test.mjs
```

최종 실행 대상은 브라우저 셸 보정 커밋 `4954450`입니다. 브라우저 셸 `5140862`, 그래프 우선 배치·범례 수정 `468d534`, 밝은 테마 범례 대비·390px CSV 스크롤·PDF 파생 미리보기 크기 제한을 포함합니다. 마지막 보정은 보기별 실행 그래프 열림·닫힘 보존과 파일만 있는 자기 버전의 정직한 표시입니다. 본 기록과 추가 회귀 검사 파일은 이 구현 커밋 위에서 별도로 검토합니다.

- 검증 총괄의 최종 7개 파일 통합 재실행: **79개 통과, 실패 0, 건너뜀 0**, 46.16초. 순수 코드·실물 파일 검사 57개와 브라우저 검사 22개입니다. 명령은 README의 5개 순수 검사 파일과 두 브라우저 검사 파일을 합친 것입니다.
- 작성자도 최종 커밋에서 두 브라우저 검사 파일을 함께 재실행: **22개 통과, 실패 0, 건너뜀 0**, 약 48초. `browser-review.test.mjs`의 11개와 `browser.test.mjs`의 11개입니다. 모든 브라우저 컨텍스트에서 잡히지 않은 오류와 외부 HTTP 요청이 없었습니다.
- `git diff --check`: 통과. Playwright 모듈 환경 변수가 없을 때는 실제 명시 오류를 확인했으며 성공이나 생략으로 기록하지 않았습니다.
- 최초 Task 7 실행은 8/11 통과였습니다. 빈 초기 페이지에서 저장소를 건드린 검사 주입 코드 2건을 HTTP 페이지에만 적용하도록 바로잡았습니다. 실제 390px 개선 화면의 CSV가 본문을 47px 넘친 문제는 담당 CSS 수정 뒤 전체 행렬로 재검사했습니다. 별도 화면 관찰에서 발견한 새 초안과 밝은 테마 범례 대비 문제도 담당 CSS 및 양 테마 대비 회귀 검사로 고쳤습니다.

실제 캡처 86개를 `control-prototype/review-output/`에 생성했습니다. 이전 실패 진단 `failure-growth-390-light.png` 1개는 별도이며 통과 근거로 세지 않습니다. 주요 파일은 `00-run-overview`, `01-design`, `02-run-and-alternative`, `03-new-input-unanalysed`, `04-fixed-inquiry`, `05-paired-review`, `06-connection/logs/audit/approval`, `07-growth-{width}-{theme}`입니다. 후보 이름·범례를 포함한 전체 후보 화면, 실행·비교 그래프, 경쟁 설명, 부분 밖 영향 표와 54개 화면 조합의 뷰포트도 있습니다. 모두 `.png`이며, 긴 페이지 전체를 한 장으로 축소하지 않습니다.

작성자가 직접 확인한 일부 캡처(`00-run-overview`, `01-design-pipeline-graph`, `02-run-and-alternative`, `03-new-input-unanalysed`, 수정 후 `matrix-1440-light-run-graph`와 `08-run-graph-390-dark`)에서는 초기 탐색·현재 맥락·전체 그래프, 후보의 이름·범례·공통 초점, 원본 PDF 파생 미리보기와 실제 범위, 새 입력의 미분석 표시가 보입니다. 작은 화면 보조 캡처는 선택 노드를 실제로 누른 뒤 그 노드와 인접 관계선을 보여 주며, 가로로 잘린 나머지 그래프 전체의 증거로 세지 않습니다. 이는 전체 캡처의 독립 시각 검토나 사용자 수용 판정이 아닙니다. 캡처는 저장소에 추가하지 않고 검사 명령으로 재생성할 수 있는 로컬 근거로 둡니다.

과거 UI-01–15 관찰 및 V02/V03 정체성 실패는 그대로 보존합니다. 새 코드 검사가 과거 실패나 사용자 미확인을 덮지 않습니다. 실제 캡처를 확인한 뒤에만 시각 판정을 갱신하며, 파일·화면 표시 검사를 DeepTwin 효과 증거로 해석하지 않습니다.

## 독립 검토와 화면 인계

Task 6의 최종 수정은 별도 명세 검토자 확인 후 작성자와 다른 품질 검토자가 통과 판정했습니다. Task 7도 작성자와 다른 두 담당자가 명세→품질 검토를 마쳤으며, 최종 코드 SHA와 검사 수를 고친 기록도 재검토했습니다. Task 7의 세 파일은 `94198e8`에 기록했습니다. 코드 변경 없이 이 절에서 직접 관찰한 범위와 인계 상태만 추가합니다.

주 에이전트는 `00`–`07`의 주요 캡처 26개를 직접 확인했습니다. 별도 시각 검토자는 `matrix-*` 54개와 `08-run-graph-*` 6개를 모두 직접 확인했습니다. 수정 후 밝은 테마 범례 6개와 390px 어두운 선택 노드 화면을 재확인해 알려진 잘림·겹침·대비 문제를 해소했습니다. 긴 페이지는 세로로 읽고 좁은 그래프·파일은 자체 탐색 영역으로 읽습니다. 이 관찰은 캡처에 보이지 않는 모든 상호작용이나 물리 IME·OS 수준 BFCache·전체 접근성을 인증하지 않습니다.
