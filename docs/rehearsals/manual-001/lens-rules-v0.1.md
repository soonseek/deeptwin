# MANUAL-001 수동 탐구 규칙 v0.1

상태: 이번 한 건의 사전 점검을 위한 수동 카드 초안. 실행 코드·설치된 렌즈 엔진·학술 검증 완료된 레지스트리가 아니다. 사용자 대안은 아직 없고 어떤 렌즈도 사용자에게 배정하지 않았다. 사용자에게 대안을 받기 전에 아래 해석 이름이나 예상 방향을 노출해 답을 유도하지 않는다.

출처: 사용자가 제공한 `DeepTwin_OpenSource_Reference_Paper_KO.pdf` 4.8절, 24–28쪽. 철학 원전 자체의 별도 검토는 수행하지 않았다. 아래 작동 규칙은 논문의 판별 질문을 수동 점검에 적용한 개발자 초안이지 철학자 전체 사상의 구현이 아니다.

공통 입력은 고정 과업·자료·원본과 이후 받은 실제 대안, 실제 관찰 차이뿐이다. 앞서 배제된 업무 설명·사용자 프로필·다른 해석자의 결론은 전달하지 않는다. 이름 붙이기나 대안의 이유를 단정하는 것이 아니라 복수 설명과 그 설명이 달리 예측하는 조건을 만든다. 새 증거가 없으면 미결이며, 조건을 구별할 수 없으면 질문을 강제하지 않는다.

## L1: 경험적 탐구

- 출처 계보: 논문 24쪽 듀이 항목, 25–28쪽 판별·새 증거 경계.
- 핵심 검사: 어떤 관찰이나 시험이 현재 설명을 지지 또는 반박할 것인가.
- 작동: 실제 차이에 관한 잠정 설명 두 개가 다른 결과를 예측하도록, 얻을 수 있는 증거 조건 하나를 바꾼 업무 상황 후보를 만든다. 응답을 받기 전에 각 설명의 예상 수행 차이와 반박 조건을 기록한다.
- 반영 금지: 모든 판단을 숫자 측정으로 대체하거나 검증되지 않은 통계를 만들어 설명을 확정하지 않는다.

## L2: 맥락적 실천지

- 출처 계보: 논문 24쪽 아리스토텔레스 항목, 25–28쪽 판별·새 증거 경계.
- 핵심 검사: 같은 일반 설명 아래에서 구체 목적·수단·시기·사정이 달라지면 수행이 달라지는가.
- 작동: 관찰 차이가 고정된 표현 선호인지 상황에 맞춘 판단인지 등의 실제 경쟁 설명이 있을 때, 그 설명들이 달리 반응할 업무 조건 하나만 바꾼다. 어떤 수행을 예상하는지 먼저 기록한다.
- 반영 금지: 맥락을 이유로 사실을 바꾸거나 사용자가 무엇이든 일관되게 했다고 사후 정당화하지 않는다.

## L3: 결과·피해 비교

- 출처 계보: 논문 24쪽 밀 항목, 25–28쪽 판별·새 증거 경계.
- 핵심 검사: 편익·피해의 크기 또는 영향을 받는 대상이 달라질 때 수행이 달라지는가.
- 작동: 실제 대안 차이에 영향·부담 배분에 관한 경쟁 설명이 있을 때만, 부담 또는 예상 결과 조건 하나를 바꿔 설명별 예측을 기록한다.
- 반영 금지: 사용자에게 특정 가치관을 부여하거나 중대한 개인 결정을 프로파일링하지 않는다. 가상의 영향 조건을 실제 결과로 기록하지 않는다.

## 적용·비교·중단

1. 실제 대안 없이 카드 적용·사용자 가설·질문 생성으로 진행하지 않는다. 일부만 대안이 있으면 그 범위에서 관찰 차이를 시작하되 영향 범위를 거기에 가두지 않는다.
2. 필요한 카드만 적용한다. 어떤 카드도 맞지 않거나 단순 사실 오류뿐이면 미적용/unknown으로 남긴다. 전체 사용자 구성개념 절차를 이미 수행했다고 표시하지 않는다. 이 세 카드가 충분하다고 미리 확정하지 않는다.
3. 후속 시도에서는 렌즈 카드를 주지 않은 탐구와 카드 기반 탐구를 같은 고정 자료·대안 및 같은 요청된 출력 한도에서 별도로 작성한다. 제공 문맥과 실제 사용량 차이는 기록하며 동등 비용을 추정으로 보장하지 않는다. 이는 전역 성능 평가가 아니라 질문의 실질적 차이를 보는 질적 점검이다.
4. 각 경로는 관찰 차이, 경쟁 설명 최대 두 개, 한 조건을 바꾼 질문 후보 최대 하나, 설명별 상이한 예상 수행 및 반박/미결 조건을 남긴다. 일반 경로에도 가설·반례를 탐구할 동등한 기회를 준다.
5. 사용자에게는 필요할 때 한 번에 한 상황만 제시하고 실제 버전/선택을 받는다. 질문을 만들었다는 사실, 사용자 동의, 철학 출처를 설명의 참 또는 학습 효과로 점수화하지 않는다.
6. 구별할 조건·상이한 예측이 없거나 렌즈 없는 탐구와 실질적으로 같으면 이번 사례에서 추가 효용을 확인하지 못한 것으로 기록한다. 사용자의 부담·거절·사례 부적합이면 멈춘다. 반복 사용자 응답을 자동 요청하는 실험이 아니다.
7. 예측이 맞아도 하나의 설명을 증명하거나 내면 원인을 복원한 것은 아니다. 새 수행 증거는 판단 가설 갱신의 근거이며, 렌즈 해석 자체를 운영 지식으로 주입하지 않는다. 학습 효과·전이·회귀·환경 승격은 이번 단계의 결과가 아니다.
