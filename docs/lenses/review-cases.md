# 렌즈 계약 문서 검토 사례

DG-L01 · 2026-09-07. 아래 기대 행동은 문서 검토 기준이며 사용자 철학의 정답이나 실제 엔진 시험 결과가 아니다. 준비 조건은 합성 검토 상황이다. MANUAL-001이나 사용자의 업무 설명을 피드백 자료로 사용하지 않는다.
