# 원전 기반 마이크로렌즈 정의 후보

DG-L01 · 2026-09-07 · 문서 초안. 아래 17개 카드는 검토할 주장 단위를 나눈 것이며 제품 최초 지원 목록, 철학자별 인격, 실행 가능한 엔진 명세가 아니다. `L-P032-01` 같은 ID는 원전 항목과 원자 주장을 연결하는 문서 식별자이고 `draft-1`은 문서 버전이다. 런타임 스키마나 등록 상태를 뜻하지 않는다. 다른 주장·전통의 추가와 기존 후보의 폐기 모두 열려 있다.

근거는 [원전 검토 목록](source-map.md)에 기록된 실제 본문 실독 범위로 제한한다. 원전을 직접 읽은 담당자와 이 후보 문서의 작성자를 구분한다. 이 문서 작성자는 그 실독 기록을 사용했으며 모든 원전을 재독했다고 주장하지 않는다. 카드의 **원전 주장**은 해당 논의의 자체 요약이고 **우리 공학 번역**은 프로젝트가 제안하는 제한적 적용이다. 어떤 원전도 아래 역할 배치, 모델, 도구, 그래프 구조 또는 LLM 효과를 처방하거나 입증하지 않는다. 직접 인용과 원문 전재는 하지 않는다.

## 모든 카드가 명시적으로 상속하는 계약

### C1 — 사용 경로의 전제와 허용 범위

아래 경로는 이 문서에서 모두 비활성이다. 각 카드의 `초기`, `비평`, `SPLI`는 C1의 전제를 줄일 수 없으며 카드 고유의 추가 조건을 명시한다.

- **초기 설계 전제:** 사용자가 확인한 업무 목적·산출물·관찰 가능한 조건과 그 자료의 사용 권한이 있어야 한다. **허용:** 그 조건에 맞는 설계 질문과 구조 후보 제안. 최초 업무 설명을 H_exp, H_phi, 사용자 철학 또는 피드백으로 승격하지 않는다.
- **비평가 반례 전제:** 접근이 허용된 원본, 검토할 실제 후보, 사전에 고정한 평가 기준이 있어야 한다. **허용:** 후보를 구별할 수 있는 반례를 제안하고 근거를 연결한다. 제안자는 반례의 타당성과 후보의 대응 성공을 스스로 최종 판정하지 않는다. 독립된 판정 절차는 별도로 필요하며 인물별 감독 에이전트를 요구하지 않는다.
- **대안 이후 SPLI 전제:** 실제 전체 또는 부분 대안, 관찰된 판단 차이, 확인된 H_exp가 모두 있어야 한다. **허용:** 그 차이에 관해 새로운 E_phi를 얻는 질문을 제안하고, 얻은 자료로 H_exp를 다시 검증한다. H_phi를 운영 규칙으로 직접 바꾸지 않는다. 부분 대안은 근거가 부분적이라는 뜻이며 후속 영향까지 그 부분에 갇힌다는 뜻은 아니다.

본 작업에는 사용자 피드백·실제 대안 자료가 제공되지 않았다. MANUAL-001과 사용자의 YouTube 업무 설명은 피드백, 시험 또는 효과 증거가 아니며 아래 합성 예시에도 사용하지 않는다. 이를 대신할 개인 자료를 요청하지 않는다.

### C2 — 판단·설계 효과의 경계

- 카드의 적용 조건은 관찰 가능한 업무 조건이다. 개인의 성격·심리 본성, 정치·종교 성향, 도덕적 서열을 추론하거나 저장하는 것은 모든 카드에서 금지한다. 법, 조직 정책, 계약, 접근성 요구, 직무 권한과 이미 확인된 업무 목적이 설명하는 차이를 렌즈 효과로 오인하지 않는다. 규정의 해석·변경 권한은 렌즈에 생기지 않는다.
- 각 카드의 예상 대비는 다른 조건을 고정하고 명시한 조건 하나만 바꿨을 때의 **검토 가설**이다. 반증 단서는 실제 효과가 없거나 기존 절차만으로 설명된다는 가능성도 포함한다. 새 질문이 없거나 판단이 동일하면 추가 가치 미확인으로 남긴다. 효과·독립적 기여는 DG-V01의 통제 비교가 필요하다.
- 구조 차이는 기존 역할 내부의 판단, 입력 범위, 원본 접근, 산출물 형식, 인계 묶음, 기억 범위, 조건부 정책 또는 평가 항목일 수 있다. 렌즈마다 새 에이전트·상위 감독·일괄 승인 단계를 만들지 않는다. 후보 충돌은 근거와 함께 보존하며 평균·다수결로 합의시켰다고 쓰지 않는다.
- 카드별 설계 효과의 역할·입출력·인계·기억·권한·평가는 모두 **우리 공학 번역**이다. 예상 이점은 검증 결과가 아니다. 문서 개정 시 이전 버전과 근거를 보존하며 검토 자격은 자동 상속하지 않는다.

### S0 — 새로 만든 합성 업무와 완전한 산출물 인계

아래 모든 사례는 이 문서를 위해 새로 만든 **박물관 전시 안내물 제작이라는 합성 공학 업무**의 서로 다른 고정 조건이다. 실제 사용자 업무, 실제 그래프·파일·실행·평가 결과가 아니다. 카드의 네 칸 비교는 설계 예시만 제시한다.

공통 작업은 허가된 소장품 카탈로그 문서·표·이미지를 근거로 안내 PDF, HTML, 이미지 캡션을 구성하는 것이다. 역할 A는 자료 해석, B는 안내물 구성, C는 형식·근거 점검을 담당한다고 가정한다. 이는 철학자 이름을 붙인 역할이 아니다.

| 단계 | 실제 형식을 유지한다고 가정하는 입출력·인계 |
| --- | --- |
| A → B | A가 만든 근거 표 CSV와 해석 문서 DOCX **전체**, 원본 카탈로그 PDF·문서·표 및 이미지에 대한 허가된 원본 접근 정보를 함께 넘긴다. 세부 단서나 이미지 자체를 요약문으로 대체하지 않는다. |
| B → C | A의 인계 묶음 전체를 유지하고 B가 만든 안내 PDF, HTML, 캡션 표 CSV, 배치 미리보기 PNG, 구성 결정 문서 DOCX **전체**를 추가한다. C는 각 원형 산출물을 열어 확인할 수 있다. |
| C 이후 | C의 확인 표 CSV·주석 문서 DOCX를 앞선 모든 단계 산출물과 함께 보존한다. 카드가 중간에 추가하는 비교표·이미지·수정본도 이 완전한 인계에 포함하며 이전 버전을 요약으로 덮어쓰지 않는다. 공개 배포는 가정하지 않는다. |

브라우저·파일 도구는 프레임워크가 소유하고 실행한다. 역할에 연결된 모델은 업무의 기존 선택 조건으로 정해지며 렌즈가 모델 이름·성능을 가정하지 않는다. A의 모델은 승인된 카탈로그·원본에 대해 브라우저/파일 **읽기 요청**을, B의 모델은 승인된 작업 경로에 새 PDF·HTML·이미지·문서·표를 만드는 **쓰기 요청**을, C의 모델은 완성본 **읽기와 별도 점검 산출물 쓰기 요청**을 할 수 있다고 가정한다. 프레임워크가 각 요청의 경로·행위 권한을 확인한다. 모델·역할·렌즈의 판단은 게시 권한, 원본 덮어쓰기, 사람에 대한 제재 권한을 부여하지 않는다. 다른 모델에 인계될 때도 원형 산출물·출처·허용 행위가 함께 전달되어야 하며 모델 자체가 파일·브라우저 소유자가 되지 않는다.

### R0 — 검토 상태를 분리하는 표기

각 카드의 `원전 검토자/범위`는 [source-map.md](source-map.md)의 실제 독자·판본·실독 범위를 가리킨다. 아래 문서 검토 통과는 출처 연결·정의 필드·사용 경계에 대한 개발 내용/명세/품질 대조다. [검토 보고서](review-report.md)의 담당자·실독 범위·수정 이력을 함께 읽는다. 학술 검토·실제 효과·용도별 사용 허가는 별개이며 모두 미완료다. 다른 담당자가 병합한 경우도 실제 독자를 바꾸어 적지 않는다.

- **출처·원전 검토자/범위:** [P001](source-map.md#p001); Polanyi, TACK 허가 영어 발췌 [「Tacit Knowing」](https://tacit-knowledge-architecture.com/object/the-tacit-dimension-excerpt/), 발췌 표기 pp.4–13, 웹 본문 32–84행 전체, 얼굴 식별부터 근위/원위 항 관계까지. root 실독, 2026-09-07. 저본 쇄와 인쇄판 무삭제 일치는 미확인이다.
- **원전 주장:** 전체를 알아보는 판단은 말로 모두 설명하지 못하는 세부 단서에 의존할 수 있다. **범위·반대 독해:** 보조적 주의를 무의식과 등치하지 않으며 완전한 암묵지 추출·영구적 전달 불가능성을 주장하지 않는다. **기능층:** 인식·해석.
- **경로별 전제 → 허용(C1):** 초기—확인된 업무에서 전체 인상과 명시 기준 사이의 누락이 우려됨 → 구체적 사례의 단서 보존 질문. 비평—원본 이미지와 후보 배치, 고정된 식별 기준이 있음 → 최종 크롭에 사라진 단서를 이용한 반례 제안. SPLI—실제 이미지·배치 대안에서 관찰된 판단 차이와 확인된 H_exp가 있음 → 어떤 부분을 보았는지 새로운 E_phi 질문 후 H_exp 검증. 어느 경로도 사람의 잠재 전문성을 진단하지 않는다.
- **관찰 조건:** 적용—모든 원본을 인계했지만 최종 크롭에서 판별에 관련된 위치·배경·관계가 빠질 수 있음. 비적용—완전한 코드 일치만 검사하는 표 변환. 기권—원본이나 구체적 선택 사례를 볼 수 없음.
- **판별 질문·예상 대비:** “같은 설명문·중심부라도 주변부 단서가 최종 크롭에 남는지에 따라 식별 판단이 달라지는가?” 원본 접근·내용은 고정하고 크롭의 손잡이 포함 여부만 바꾸면, 손잡이를 자른 후보에서는 더 넓은 크롭을 제안하고 이미 포함한 후보는 유지할 수 있다. **반증 단서:** 손잡이 유무가 판단을 바꾸지 않거나 기존 이미지 품질 기준이 차이를 충분히 설명함.
- **교란·금지:** 저작물 열람권, 해상도, OCR 손실, 전문 직무의 기존 점검을 먼저 구별한다. C2의 성격·정치·종교·도덕 서열 추론은 금지한다.
- **우리 공학 번역—설계 효과:** 역할은 A·B 그대로; 원본 이미지·설명문 입력은 S0대로 이미 유지하며 출력에 단서 위치 표 CSV를 제안; 인계에는 크롭과 판별 단서의 대응을 추가할 수 있다. 기억은 선택 사례와 관찰된 단서만 보존; 권한은 원본 읽기 범위 유지; 평가는 최종 표현에서 누락한 단서로 생기는 오식별 여부를 묻는다. **이유·예상 이점:** 원본 보유와 최종 표현의 단서 보존을 구별. **비용:** 위치 표시·비교 열람 시간. **무변경 조건:** 기존 구성 과정이 같은 단서를 이미 보존하거나 추가 단서가 없음.
- **고정 합성 조건(S0):** 전체 원본·설명문을 받은 B가 같은 유물 사진의 PDF 크롭을 선택한다. **렌즈 없이 고려:** 원본 접근·완전 인계·해상도·캡션 정확성. **구체적 추가 질문:** 사진 가장자리의 손잡이가 분류를 바꾸는데 중앙 크롭에서는 사라지는가? **가능한 구조 차이:** B 내부에서 단서 위치와 최종 크롭을 대응시켜 넓은 크롭을 선택. **반대·불필요 조건:** 기존 사진 점검이 이미 같은 질문·크롭을 선택했다면 추가 가치 미확인.

### L-P030-01 · draft-1 · 준칙의 보편법칙 가능성

- **출처·원전 검토자/범위:** [P030](source-map.md#p030); Kant, Abbott 번역 Gutenberg #5682 [본문](https://www.gutenberg.org/cache/epub/5682/pg5682-images.html)·[텍스트](https://www.gutenberg.org/cache/epub/5682/pg5682.txt), 제1절 629–715행과 제2절 1370–1525행, 연결 문맥 1900–2040행 실독. l01_sources_west, root 병합, 2026-09-07. Abbott 저본 쇄와 Ak 정밀 경계 미확인; Gregor/Timmermann 2012 본문 미실독.
- **원전 주장:** 선택 준칙을 모두에게 적용되는 법칙으로 의욕할 수 있는지 묻는다. 제2절의 구별은 그런 보편법칙을 모순 없이 생각할 수 있는지와, 생각할 수 있더라도 그 법칙을 모순 없이 의욕할 수 있는지를 나눈다(위 실독 범위의 텍스트 1511–1519행). **범위·반대 독해:** 다수결·결과 합계·선호 투표·모든 사례의 기계적 동일 처리와 다르다. 소속에 따른 대칭성은 자기 예외를 찾는 보조 점검일 뿐 이 구별을 대신하지 않는다. L-P030-02와 서로 다른 질문이지만 원전에서는 연결된 공식들이며 독립 윤리학 두 개나 독립 효과 증거 두 표가 아니다. **기능층:** 규범.
- **경로별 전제 → 허용(C1):** 초기—확인된 업무의 선택을 조건·행위·목적으로 명시할 수 있고 판단 여지가 있음 → 그 준칙의 보편 채택과 의욕 가능성 질문. 비평—실제 후보의 준칙, 그것이 전제한 관행·목적, 고정 기준이 있음 → 모두가 채택할 때 그 전제가 유지되는지에 관한 반례 제안. SPLI—실제 선택 대안과 판단 차이·확인된 H_exp가 있음 → 어떤 조건에서 무엇을 왜 하려는 준칙이었는지 E_phi 질문 후 H_exp 검증. 숨은 동기나 사용자 철학을 추정해 준칙을 대신 작성하지 않는다.
- **관찰 조건:** 적용—‘이 조건에서 이 목적을 위해 이 행위를 한다’는 선택이 다른 사람들의 신뢰·약속·협력 관행을 전제함. 비적용—준칙 선택의 여지가 없는 파일 형식 변환이나 이미 확정된 기계적 검사. 기권—조건·행위·목적 또는 전제한 관행을 확인할 근거가 없음.
- **판별 질문·예상 대비:** “이 조건에서 이 목적을 위해 이 행위를 한다는 준칙을 모두가 채택해도, 그 행위가 전제하는 관행과 목적 달성을 모순 없이 생각할 수 있는가? 생각할 수 있다면 그 법칙도 모순 없이 의욕할 수 있는가?” 비교할 합성 준칙은 조건=‘귀속 근거가 미확인/확인된 상태에서 안내물을 작성함’, 행위=‘그 귀속을 확정 사실로 표현함’, 목적=‘안내물에 대한 신뢰를 얻음’이다. S0의 모든 원형 산출물·권한·역할·PDF와 HTML 요구를 고정하고 귀속 근거의 확인 상태만 바꾼다. 미확인 상태라면 같은 상황에서 모두 확정 표현을 사용할 때 그 표현을 믿는 관행을 계속 전제할 수 있는지 묻고, 미확인을 드러내는 표현과 준칙 재검토를 제안할 수 있다. 확인된 상태라면 그 이유로 같은 수정 제안을 하지 않을 수 있지만, 그것만으로 의욕 가능성까지 통과했다고 판정하지 않는다. **반증 단서:** 가정한 관행이 실제로 전제되지 않았거나, 기존 정확성 정책만으로 같은 질문·표현을 이미 선택하여 추가 판단 차이가 없음.
- **교란·금지:** 출처 표시 계약·법적 의무·자료별 권리·기존 정확성 정책을 우선 구별한다. 근거 추적성 검사 실패만으로 보편법칙 불가능이나 도덕적 실패를 판정하지 않으며 자동 칸트 판정도 하지 않는다. C2의 개인 도덕성·정치·종교·성격 평가 금지.
- **우리 공학 번역—설계 효과:** B의 기존 역할에서 선택의 조건·행위·목적을 명료화; 입력은 확인된 업무 목적·귀속 근거와 전제한 관행, 출력은 준칙 표 CSV와 보편 채택/의욕 가능성의 별도 질문을 담은 문서 DOCX; S0 인계에 근거·질문·미해결 상태를 함께 보존한다. 기억은 업무 선택과 근거만, 사용자 철학은 저장하지 않음; 권한은 질문·대안 제안 범위이고 확대 없음; 평가는 준칙의 세 요소, 보편 채택에서의 전제 유지 논거, 생각 가능성과 의욕 가능성의 구별을 확인하며 도덕적 합격 점수를 산출하지 않는다. **이유·예상 이점:** 자기 선택이 의존하는 관행을 모두의 같은 선택이 무너뜨리는지 드러냄. **비용:** 준칙 명료화·해석 검토 부담. **무변경 조건:** 기존 절차와 질문·표현 선택이 같거나 준칙을 구별할 근거가 없음.
- **고정 합성 조건(S0):** 전체 원형 자료를 인계받은 B가 카탈로그에서 아직 확인되지 않은 작가 귀속을 안내 PDF·HTML에 표현한다. 신뢰할 만한 안내라는 확인된 업무 목적과 모든 S0 요구는 고정한다. **렌즈 없이 고려:** 근거 정확성·불확실성 표시·캡션 길이·완전 인계. **구체적 추가 질문:** 미확인 귀속도 신뢰를 얻으려고 확정 표현한다는 준칙을 모두가 채택하면, 그 확정 표현을 믿는 관행을 계속 전제할 수 있는가? 그렇다고 생각하더라도 그 법칙을 의욕할 수 있는지는 별도로 물었는가? **가능한 구조 차이:** B의 기존 편집 기록에 조건·행위·목적과 두 질문을 분리해 남기고, 미확인 표현 후보 및 미해결 논거를 전체 산출물과 함께 C에 인계. **반대·불필요 조건:** 기존 정확성 검토가 같은 질문·표현을 이미 선택했다면 추가 가치 미확인이며 단순 추적성 개선을 이 렌즈의 고유 효과로 세지 않음.
- **상태(R0):** 문서 검토 통과(범위 R0) / 학술 미검토 / 실제 효과 미검증 / 운영 사용 미채택.

- **출처·원전 검토자/범위:** [P035](source-map.md#p035); Foucault, Sheridan 번역·Vintage 1995 표기 [Panopticism 전사](https://www.foucault.info/documents/foucault.disciplineAndPunish.panOpticism/) 전체, 페스트 규정부터 제도 비교 결말까지(사이트 pp.195–228 표기). l01_sources_modern 실독, root 병합, 2026-09-07. 1977 인쇄판과 쪽·이문 대조 미실시; The examination 미실독을 보완한 것으로 세지 않는다.
- **원전 주장:** 대상은 자신이 언제든 관찰될 수 있음을 알지만 지금 실제로 관찰되는지는 확인할 수 없는 비대칭 구조에서, 관찰이 간헐적이어도 대상이 권력의 요구를 스스로 유지하게 할 수 있다고 분석한다. 핵심 위치는 Panopticism의 중심 탑 설명 직후, 의식된 지속적 가시성과 보이는/확인 불가능한 권력을 다루는 단락이다. **범위·반대 독해:** 역사적 제도 권력의 분석을 작업 로그로 옮기는 것은 유비이다. 열람자 목록을 모른다는 사실만으로 이 기제가 성립하지 않으며, 몰래 수집해서 대상이 관찰 가능성 자체를 모르는 경우와 구별한다. 모든 관찰의 금지나 소프트웨어 로그의 확정된 심리 효과를 주장하지 않는다. 정상 기준·순위 결합(L-P035-01)과 다른 주장이다. **기능층:** 권력·제도, 인간관·동기.
- **경로별 전제 → 허용(C1):** 초기—사람의 작업 기록·관찰 가능성에 대한 당사자의 인지 근거·관찰 시점 확인 가능성을 확인할 수 있음 → 관찰 관계의 비대칭 질문. 비평—실제 기록 후보·관련 안내와 명시적 진술·고정 기준이 있음 → 단순 고지만으로 관찰 관계가 대칭화됐다는 주장에 대한 반례 제안. SPLI—실제 기록·공유 대안과 판단 차이·확인된 H_exp가 있음 → 어떤 관찰 관계를 바꾸려 했는지 E_phi 질문 후 검증. 개인의 숨은 심리 상태를 로그에서 추정하지 않는다.
- **관찰 조건:** 적용—기여자가 상시 열람 가능성을 안다는 근거가 있고 실제 열람 시점은 확인할 수 없음. 비적용—사람과 무관한 파일 손상 점검; 관찰 가능성 자체를 모르는 상황은 이 특정 자기규율 기제의 적용 근거가 아니며 별도 개인정보·권한 검토 대상이다. 기권—인지 여부·실제 관찰 확인 가능성·보관 목적의 근거가 없음.

- **교란·금지:** 보안 감사 의무·기밀 자료 접근·보존 규정·직무 권한을 분리한다. C2의 성격·정치·종교·도덕 서열 추론, 몰래 감시하기 위한 설계 사용 금지.
- **우리 공학 번역—설계 효과:** A·B·C 역할은 유지; 입력은 승인된 로그 사용 목적·열람 규칙·안내와 명시적 인지 근거, 출력은 이력 표와 관찰 가능성/실제 관찰 확인 가능성을 나눈 문서; S0 인계에 이를 연결한다. 기억은 필요한 사건·근거와 정해진 보존 범위이며 숨은 심리 프로필은 없음; 권한은 기존 열람권을 넘지 않으며 확대 필요 시 후보로만 남김; 평가는 두 조건의 근거와 행동 효과의 미확인을 따로 기록한다. **이유·예상 이점:** 기록 고지와 관찰 관계의 대칭성을 혼동하는 문제 발견. **비용:** 조건·대안 검토 부담. **무변경 조건:** 특정 기제의 조건이 성립하지 않거나 기존 검토가 같은 질문·설계에 도달함. 실제 기록 삭제·수집 확대·은밀한 감시 실험을 허용하지 않는다.
- **고정 합성 조건(S0):** 가상의 캡션 기여자가 자신의 수정 이력을 관리자가 언제든 읽을 수 있음을 알고 있지만 지금 읽는지는 확인할 수 없다고 명시한 상황이다. 필수 로그·PDF·HTML·완전 인계·권한은 고정한다. **렌즈 없이 고려:** 변경 추적·오류 복구·수집 고지. **구체적 추가 질문:** 고지를 했다는 사실과 실제 관찰 시점을 확인할 수 있다는 사실을 혼동하고 있는가? **가능한 구조 차이:** 기존 이력 점검에 두 조건과 관찰 관계 설계 대안을 구별한 문서를 연결하되 권한 확대나 행동 개선을 확정하지 않음. **반대·불필요 조건:** 기존 검토가 같은 관찰 관계를 다뤘다면 추가 가치 미확인이며, 파일 복구만의 문제라면 이 적용을 제외함.

- **관찰 조건:** 적용—미리보기의 예기치 않은 결과가 원래 문제 설정을 의심하게 하며 수정 여지가 남음. 비적용—최종 배포 후 변경 불가하고 회고 기록만 가능함. 기권—무엇이 예상 밖이었는지 또는 수정 가능한 시간·권한이 불명확함.
- **판별 질문·예상 대비:** “이 실패는 같은 해법을 다시 시도할 문제인가, 무엇을 만들고 있는지의 설정을 바꿀 단서인가?” 내용은 고정하고 미리보기에서 한 도판이 두 물건의 관계를 보여준다는 관찰만 추가되면 ‘개별 캡션 축약’에서 ‘관계 설명’으로 재구성하는 후보를 낼 수 있다. **반증 단서:** 단순 렌더 오류이거나 기존 수정 절차가 이미 같은 재구성을 함.
- **교란·금지:** 기술 오류·범위 변경 승인·마감·편집 권한·요구사항 누락을 구별한다. C2의 성격·정치·종교·도덕 서열 추론 및 자기성찰 문장만으로 능력 향상 주장 금지.
- **우리 공학 번역—설계 효과:** B의 기존 제작 역할 안에서 문제 설정을 재검토; 입력은 실제 형식의 중간 PDF·PNG와 예상, 출력은 수정된 PDF·HTML·캡션 표 및 재구성 이유 DOCX; S0는 전후 산출물 전체를 C에 전달한다. 기억은 놀람의 관찰·전후 문제 설정·수정 범위; 권한은 승인된 작업 범위, 확대가 필요한 후보는 실행하지 않음; 평가는 수정이 문제 설정 변화인지 단순 재시도인지 구별한다. **이유·예상 이점:** 잘못 잡은 문제의 반복 방지. **비용:** 재구성·후속 영향 점검. **무변경 조건:** 문제 설정이 유지되거나 수정 가능 시간이 없음.
- **고정 합성 조건(S0):** B가 PDF 미리보기를 보며 쌍을 이룬 유물 설명이 각각 떨어져 관계를 잃었다는 상황을 가정한다. **렌즈 없이 고려:** 문구 축약·페이지 넘침 수정. **구체적 추가 질문:** 이 작업을 두 개별 캡션 작성으로 본 설정이 관찰된 관계를 놓쳤는가? **가능한 구조 차이:** B 내부에서 관계 설명 단위로 재구성해 PDF·HTML·캡션 표를 함께 수정하고 전체 전후 산출물을 C에 인계. **반대·불필요 조건:** 관계는 이미 표현되어 있고 문제는 단순 여백 오류뿐임.
- **상태(R0):** 문서 검토 통과(범위 R0) / 학술 미검토 / 실제 효과 미검증 / 운영 사용 미채택.
