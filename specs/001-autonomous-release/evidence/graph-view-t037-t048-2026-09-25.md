## What landed

- **`graphs-v1`: `GET|HEAD /api/v1/graphs/{id}/versions/{version}`** (installed routes
  72 → 73).
  - The owner's read of one stored functional graph, admitted through
    `GraphVersion.from_untrusted` exactly as a run does.
  - A record that does not parse is refused (400), never shown half-read.
  - Nothing edits, compiles or runs a graph (`app/services/graphs.py`).
- **`app/static/graph.mjs`.**
  - **Layout.** Layers follow the triggering edges from the entries, breadth first, so a
    loop's cycle cannot grow the drawing. Observation edges are drawn dashed and never order
    nodes.
  - **Drawing.** An SVG shows every node (id, kind, responsibility) and edge, beside a
    keyboard-reachable list of node buttons.
  - **Node details.** Selecting a node shows everything the graph states about it: kind,
    responsibility, slots, failure policy, required approvals, grants, model binding with
    choice and capabilities, tools, memory, and incoming and outgoing edges.
  - **Run states.** Node states come only from the run's recorded outcome: completed,
    failed, pending, awaiting approval, or not visited.
  - **Comparison.** `compareGraphs` lists the nodes, edges, bindings and contracts that were
    added, removed or changed (with the changed fields). `focusDifference` gives one node's
    same-focus difference with its details on each side.
  - All text goes through `textContent`.
- **The observe page** (`#run-graph`) draws the selected run's graph next to the run panel.
