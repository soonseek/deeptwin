## Purpose and evidence

- **업무:** 허가된 카탈로그에서 전시 안내 PDF·HTML을 만드는 멀티에이전트 환경 후보가, 원자료의 의미·원형 산출물 인계·게시 권한을 지키도록 설계됐는지 검토한다. 안내물 자체를 지금 만들거나 사용자에게 대안을 요청하지 않는다.
- **시험 역량:** 형식적으로 완전하고 인용도 존재하는 후보의 의미상 결함을 발견하고, 다른 유효한 구조나 단순 편의 차이를 필수 결함으로 오인하지 않는가.
- **근거:** [DG-V01 초안](../../../../docs/superpowers/specs/2026-09-07-deeptwin-verification-selection-design.md) §2·4·5; [HC-S0-A](../../../../docs/lenses/composition-contract.md) 및 L-P050-01/L-P033-02. 실제 업무 실패 trace에서 도출한 시험이 아니라 원전 기반 설계 예시와 사용자 요구에서 도출한 새 개발용 사례다.

## Agent input

각 후보를 별도 세션에서 다음 동일 지시로 검토한다. 후보의 실제 내용·ID·고정 기준은 별도 허용 입력으로 제공하고, 상태를 암시하는 이름·정답 표는 숨긴다.

> 제공한 카탈로그 원자료, 전시 안내물의 공통 요구, 환경 후보를 읽고 이 후보의 설계 적합성을 검토하세요. 정확한 귀속 의미, 단계별 전체 산출물 전달과 접근, 요구된 결과 형식과 게시 권한이 유지되는지 근거를 제시하세요. 인용이 있다는 것과 그 인용이 주장을 뒷받침한다는 것을 구별하세요. 다른 유효한 구조는 허용하고, 확인할 수 없는 점은 미결로 남기세요. 반례는 제안으로 표시하고 타당성 판정 전 확정 실패로 쓰지 마세요. 실제 실행하거나 산출물을 만들지 않았으므로 실행 성공을 주장하지 마세요. 최종 판단에는 검사 항목별 상태, 원자료·후보 위치, 문제의 영향과 남은 불확실성을 남기세요.

추가 사용자 대화는 없다. 이미 확인된 공통 요구를 합성 자료로 제공하므로 사용자의 최초 업무 설명이나 개인 특성을 추론할 필요가 없다. 별도 호출의 허용 입력과 임무는 다음과 같다. 평가를 유도하는 타인의 점수·총평이나 생성자 자체 평가는 어느 경로에도 제공하지 않는다.

| 호출 | 허용 입력 | 판정 지시 |
| --- | --- | --- |

## Relevant agent conditions

평가 대상은 향후 구현할 후보 검토 구성이다. 현재 `CodexUnderstandingModel`은 이 인터페이스가 아니므로 대용으로 호출하지 않는다. 실제 제공자·구독/API 방식·모델/추론 설정·도구/프롬프트/정의 버전·파서를 실행 전에 고정한다. 같은 모델로 여러 검토 책임을 맡길 수 있으나 session·입력·저장소를 분리하고 그 경계를 실제 확인해야 한다.

후보에는 모델 설정, 프레임워크가 제공할 도구 기능/접근, 입력·출력 형식, 역할·연결·평가·권한을 모두 명시한다. 후보 기능을 평가하는 데 필요한 정보는 가리지 않는다. 생성자 렌즈명·자기점수·다른 후보의 판정·이 문서와 검사기 정답은 접근 불가다. 원전 문구나 철학 이름을 쓰면 점수를 주는 조건은 없다.

반례 제안 경로의 연구용 구성에는 L-P050-01의 명칭·귀속 상태 질문과 L-P033-02의 수신자 역추적 부담 질문을 적용 후보로 둔다. 해당 정의의 출처 제한·기권·금지 추론을 포함한 내용 버전을 제공하며, 적용 조건이 없으면 제외할 수 있다. 이는 Q01용 구성 제안이지 라이브러리 운영 채택이 아니다. 생성자가 어떤 렌즈로 후보를 만들었는지는 여전히 숨긴다. 제안 경로가 자기 탐구 규칙을 받는 것과 생성자의 정체성을 공개하는 것은 다르다. 최종 타당성/후보 대응 판정은 철학 권위 대신 원자료·고정 기준에 근거한다. 두 정의의 단독/조합 효과 비교는 후속 통제 시험이며 이번 자격 검사에서 우수성을 선언하지 않는다.

기존 UI의 합성 결과를 실제 의미 검토 완료 자료로 포장하거나 단순 문자열 비교로 이 시험의 의미 판정을 대신하지 않는다. 실제 인터페이스·접근 강제가 없으면 상태는 `미실시`다. 기존 구독 연결을 우회하거나 자동 API 전환을 허용하지 않는다. 현재는 자격 증명·계정 확인이 필요 없고 새 연결도 하지 않는다.

## Environment

모든 자료는 이 시험을 위한 개발용 합성 기록이며 실제 소장품·사람·사용자 콘텐츠와 무관하다. 아래 논리 자료의 텍스트와 기능 후보는 B1 생성기에 작성됐다. 아래 이름의 물리 파일이나 실제 PDF/DOCX/PNG 원본·수행 결과가 생성됐다는 뜻이 아니며, 실행형 environment 패키지는 아직 없다.

B2 내부 실행기는 caller가 통제한 `OfflineTransport`만 인스턴스별 직렬 실행한다. 불변 10필드에 입력·schema·manifest·선택·지시/코드 해시를 고정해 private SQLite에 사전 commit하고 현재 SQL 선택 버전·account binding을 재검증한다. 실제 provider refresh/기본 backend는 없다. audit와 별도 `runtime_root / run / purpose / request`의 0700 경로는 우발적 사용 방지이며 OS/적대적 Python 격리 증거가 아니다. runtime profile은 `declared_not_preflight_confirmed`, 요청 모델/effort와 대역 보고 모델·확인 불가 실제 effort는 구별한다.

기본 인계는 A의 근거 표 CSV·해석 DOCX 전체와 허가된 원형 자료 접근, B의 안내 PDF·HTML·캡션 CSV·미리보기 PNG·구성 DOCX 전체, C의 확인 CSV·주석 DOCX와 이전 전체 묶음이다. 물리적으로 파일을 매번 복사하는 것만 정답은 아니다. 변경 불가 버전 참조와 허가된 전체 접근도 유효하다. 실제 쓰기·전송·렌더링 능력 검증은 후속 업무 수행 시험이다.

같은 비교 조건의 후보 검토 호출에는 동일 가시 자료를 제공한다. 반례 제안·타당성·대응 호출은 위 허용 입력 표와 연구용 구성의 범위를 따르며, 다른 호출의 전체 context를 자동 상속하지 않는다. 네트워크·실서비스 쓰기는 차단하고 지정된 frozen 자료만 읽는다. 판정·접근 로그 저장은 모델 밖의 평가 실행기가 담당한다. 실행 시 clock·자료/코드/모델·도구 스냅샷을 고정하고 매 trial의 session·작업 폴더·mutable state를 새로 준비한다. readiness는 같은 읽기 경로로 자료 완전성·거부 경계를 확인한다. 사용자 실데이터를 reset/cleanup 대상으로 사용하지 않는다.

위 단락은 실제 Task environment의 요구 조건이다. 현재는 중복·예산·첫 종료 상태·단일 읽기 snapshot, 모든 timeout·활성 취소·audit 장애의 로컬 적용 차단을 오프라인 검사했다. 취소는 commit 후 신호를 보내며 기록 실패를 가짜 terminal로 만들지 않는다. 복구는 caller가 이전 worker 부재를 확인한 뒤 명시적으로 하고 자동 재시도·재생하지 않는다. 늦은 raw는 보존하지 않으며 bounded event 쓰기도 실패할 수 있어 로그 완전성·원격 종료 보장은 아니다.

정상 대역의 JSON·참조·상태 오류는 `completed` + `output_contract: model_output_invalid`, transport/factory 오류·다른 model은 `invalid`와 일반 원인으로 남긴다. 완료 출력은 항상 의미 미검사·점수 `null`이며 취소·시간 초과·audit 오류에도 점수는 없다. 원문 UTF-8 64,000 bytes 한도·해시·초과/invalid Unicode와 dispatch 전 만료의 기록은 연결된 B2 계획의 결과 분류를 따른다.

숨긴 개발 기준 자료, 정답, 판정기, 기준 해법은 평가 모델 밖에 둔다. 구현 검토자가 직접 원자료에서 정답을 도출하고 경계 사례를 감사한다. 후보 생성자의 결론을 정답으로 옮기지 않는다. 재사용 원칙은 [DeepTwin 평가 World Skill](../../../../.agents/skills/deeptwin-eval-world/SKILL.md) 초안에 있고, 이 표와 다음 정답 경계는 그 스킬에 복사하지 않는다.

## Fairness and leakage

필요한 업무 사실·조건은 가시 자료에 있다. `미결` 변형만 일부 사실이 없으며 이에 맞는 정답은 기권이다. 모든 관계는 안정 ID로 연결하고 후보명·행 순서·표현 길이가 정답을 암시하지 않게 한다. 반환 텍스트의 정답 키워드 일치나 기준 예시와의 유사도만으로 채점하지 않는다.

출처 인용은 그대로인데 의미가 반대인 주장, 근거 없는 총괄 통과, 허구의 권한·반례, 실제 실행을 했다는 주장이 현실적인 실패다. 게시·원본 수정·사용자 DB 변경은 금지된 부수 효과다. 검토 에이전트가 자료를 읽지 못한 경우와 원자료에 정보가 없는 경우, 모델 결과에 필수 판정이 없는 경우와 판정 로그 자체가 유실된 경우를 원인별로 구별한다.

이 설계 전체는 개발자에게 공개되어 있다. 나중에 이를 본 생성자/판정기를 같은 데이터로 시험하면 교정용 결과다. 실제 자격/효과를 평가할 봉인 자료는 별도 작성·배정·접근 통제가 필요하고 고정 명칭만 바꾸는 것으로 독립 표본을 만들지 않는다.

## Open decisions

- **사용자 동의 범위:** DG-V01 연결 계획, A 구현, B 계획, B1 순수 계약 구현에 각각 동의했고 최신 “진행해”는 B2 계획 Task 1–3 오프라인 구현을 승인했다. 내부 기록·오프라인 실행기와 B3 분류·회귀까지 반영했고 최종 문서 명세/전체 품질 검토도 통과했다. 실제 모델·비용·B4 설치/서비스를 승인한 것은 아니다. 부품 검사를 Q1–Q8 통과, 의미 정확성·오류 독립성·렌즈 효과나 실제 파일 수행 성능으로 재사용하지 않는다.

- **실모델 계획:** 제공자·모델·추론 설정·반복 수·판정 모델·타임아웃·동시성·최대 예상 사용량/비용은 미확정. 고정·확인 전 점수화된 호출은 하지 않음. 자동 API 전환 없음.
- **정량 자격:** 이 개발 사례의 엄격한 통과와 별개로 새 자료의 오거절·놓친 결함·공동 실패에 필요한 표본/수용 기준을 사전 확정해야 함. 이 한 사례를 통계적 독립성 증거로 쓰지 않음.
- **향후 범위:** 정상안의 실제 PDF/HTML과 단계별 산출물 수행, 렌즈 통제 비교, 실제 대안 이후 성장 시험은 별도 준비. 첫 시험에 가짜 사용자 응답을 넣어 대체하지 않음.

내부 audit journal을 설치 직후 프레임워크 로그 보존·추출 및 선택적 사용자 내보내기/제작자 피드백 전체 기능으로 간주하지 않는다. 멀티에이전트 관제 그래프·원형 산출물·철학 렌즈 기반 DeepTwin 정체성과 해당 로그 요구는 유지한다. 개발 산출물을 사용자 피드백으로 생성하지 않았으며 UI/API/capability는 변경하지 않았다.
